# KTOYA / «КтоЯ — Книга жизни»

> Твоя жизнь заслуживает книги.

## Статус

**Этап:** проектирование первой платной Beta.

Текущий продуктовый и UX-baseline утверждён; ближайший шаг — первый полноценный современный визуальный вариант для компьютера и телефона, затем техническая архитектура и реализация.

Кода приложения в репозитории пока нет намеренно: технологический стек и структура кода выбираются после визуальной проверки UX, а не создаются заранее пустыми заготовками.

## Что такое «КтоЯ»

«КтоЯ — Книга жизни» помогает человеку рассказывать реальные истории голосом или текстом, уточнять важные детали с помощью ИИ, подтверждать итог и постепенно собирать собственную Книгу жизни.

Долгосрочно KTOYA развивается в сторону умной книги, пазлов/карт, семьи, социальной сети и цифрового наследия. Эти стадии архитектурно учитываются, но не перегружают первую Beta.

## Как работаем параллельно

Отдельного обязательного управляющего чата нет. Существенная задача получает свою ветку и Pull Request. Разные чаты/агенты могут одновременно делать UX, исследования, архитектуру, код и тесты, если не перезаписывают один и тот же участок без синхронизации.

После слияния именно `main` является источником текущего состояния. Полные правила — [`docs/13-WORKFLOW.md`](docs/13-WORKFLOW.md).

## Где личные данные

GitHub — канон продукта, документации и кода, **не вторая биография Ильи**. Личные истории, здоровье, датированная хронология, карта личности и другие личные сведения канонически хранятся в личной базе Google Drive и используются проектом только в необходимом объёме.

## Главные принципы

- человек остаётся Автором;
- ИИ помогает, но не придумывает биографические факты;
- всё закрыто по умолчанию;
- уже созданные воспоминания не становятся заложником оплаты;
- книга должна быть переносимой и восстановимой;
- новая идея не задерживает текущую Beta, если не нужна текущему этапу;
- следующий этап достраивает систему без полного переписывания ядра.
