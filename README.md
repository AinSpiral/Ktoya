# Что такое KTOYA

KTOYA — это цифровая платформа исследования личности и сохранения человеческого опыта.

Проект объединяет:

- интерактивную книгу жизни;
- ИИ-помощника;
- социальную платформу;
- цифровое наследие;
- конструктор книг жизни;
- систему самоисследования;
- платформу объединения людей.

Главная цель проекта — помочь человеку лучше понять себя, увидеть свою жизнь целостно, сохранить опыт и передать его следующим поколениям.

# Основные принципы

1. Любая идея фиксируется.
2. Хорошие идеи не удаляются.
3. Все решения имеют объяснение.
4. Документация важнее кода.
5. Архитектура важнее реализации.
6. Пользователь полностью управляет своими данными.
7. Проект развивается постепенно и сохраняет преемственность.

# Долгосрочная цель

Создать новую форму цифрового наследия человечества, где каждый человек сможет сохранить свою жизнь в интерактивном формате, исследовать себя, объединяться с другими людьми и передавать опыт будущим поколениям.
